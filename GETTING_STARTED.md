# Работа на новом компьютере

Проект предназначен для Windows. Одного Codex недостаточно для вычисления геометрии: ему также нужны Git, Git LFS, Python 3.10+ и Blender. Скрипт setup.ps1 проверяет инструменты и по ключу -InstallMissing устанавливает недостающие через Windows winget. Установка может потребовать системного подтверждения. Учётная запись GitHub нужна для отправки коммитов.

## Получение проекта

Попросите Codex установить Git и Git LFS, клонировать этот репозиторий, открыть его как проект и выполнить:

```powershell
./setup.ps1 -InstallMissing -UserName "Ваше имя" -UserEmail "Ваш email или GitHub noreply"
```

Git LFS скачивает текстуры и прочие бинарные ресурсы, которые остаются в репозитории. Файлы `.blend` в Git не входят: это локальные превью, их собирает Python. Не используйте Download ZIP как замену клонированию с LFS.

Для уже установленного Blender вне стандартных каталогов задайте переменную BLENDER_PATH с полным путём к blender.exe. При необходимости перезапустите Codex после установки инструментов.

## Создание моделей

Навык находится в .agents/skills/sdelai-horosho/ и переносится вместе с Git. Откройте новый чат в корне проекта и напишите, например:

> Используй $sdelai-horosho («Сделай хорошо»). Создай [модель] в Projects/SS/[выбранный стиль]/.

Укажите стиль явно. Первоисточник модели — Python-скрипт в каталоге этого стиля. Навык меняет скрипт, собирает локальное превью `.blend`, проверяет геометрию и коммитит Python, JSON и описание. Сам `.blend` в коммит не входит. GLB без отдельного запроса не создаётся.

Сборка превью стилей SS, в новый каталог:

```powershell
python Tools/Rebuild/rebuild.py --style MilitaryArmor --work .generated/MilitaryArmor
```

Допустимые стили: `ChunkyModular`, `MilitaryArmor`, `CorporateHiTech`. Для первых двух рецепты исполняет Blender, CorporateHiTech собирает сам Python. Ключ `--publish` копирует собранные `.blend` в проект только туда, где файла ещё нет.

Отдельные сборки запускаются так же, как их скрипт: `blender --background --python Projects/MechaFighter/AnimeKnightmare/Tools/build.py` и `blender --background --python Projects/GoMedieval/NiceAndCute/Scripts/build_human.py`.

Посмотреть проект: `./serve.ps1` и http://127.0.0.1:8769/viewer.html. Существующие GLB отображаются напрямую. Локальный `.blend` открывается в Blender или через кнопку загрузки просмотрщика.

## Совместная работа

Для отправки в основной репозиторий владелец должен выдать другу права collaborator. Иначе друг может работать в собственном fork и присылать pull request. Использовать собственную авторизацию GitHub и собственное имя/email Git; они не хранятся в файлах проекта. Автоматический коммит не означает автоматический push: попросите Codex отправить изменения отдельно.

Перед началом новой задачи обновите чистую рабочую ветку через git pull --ff-only. При совместной работе создавайте отдельную ветку задачи. При конфликте не применяйте force push и не стирайте чужие изменения.
