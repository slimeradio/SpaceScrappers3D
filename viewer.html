Цвет и текстуры

Цвет умножается на цвет текстуры. Для исходных цветов карты выберите белый. Карты библиотеки содержат только цвет.

Сохранение

Правки сохраняются в этом браузере отдельно для блока и деталей. JSON переносит оформление, glTF / GLB — текущую видимую модель с материалами и анимациями.
