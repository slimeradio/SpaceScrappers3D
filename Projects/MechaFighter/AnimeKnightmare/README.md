# MechaFighter / AnimeKnightmare

Три авторских боевых робота в духе Knightmare Frame из Code Geass. Это новый изолированный проект: материалы и модели других проектов не использованы.

Визуальное направление: вытянутые ноги, узкая талия, гранёная многослойная броня, контрастный механический каркас, выступающая задняя кабина, колёса Landspinner, светящиеся сенсоры и специализированное вооружение. Ориентир: https://geass.jp/R-geass/nightmare.php

## Роботы

| Модель | Образ | Оснащение и задуманные способности |
| --- | --- | --- |
| MF-01 Aureole | Белая броня, золото, зелёные сенсоры | Два вибромеча, щит, колёсный рывок, тросовые захваты |
| MF-02 Kurenai | Красный штурмовик с асимметричной рукой | Большая радиационная клешня, тепловая перегрузка, клинок, малый щит, рывок с захватом |
| MF-03 Obsidian | Тёмный крылатый тяжёлый робот | Две плечевые пушки, энергетические крылья, концепции управления дронами и проекции барьера |

Способности описаны как направление будущей игры. Здесь созданы модели и метаданные; игровая логика боя, эффекты способностей, скелет и боевые анимации не реализованы.

## Исходники

`Parts/` содержит отдельные редактируемые Blender-библиотеки: корпус, голова, плечо, рука с пальцами, нога с колёсами, поясная броня, меч, щит, клешня, пушка, крыло, двигатель. Внутри деталей бронепанели, шарниры, приводы, вентиляция, сенсоры и крепления остаются отдельными объектами.

`Blocks/` содержит три самостоятельных файла Blender, описания сборки, передние и задние предпросмотры. Геометрия деталей повторно используется внутри сборки. Узлы сборки имеют отдельные именованные mount-объекты для последующей постановки поз; это не полноценный анимационный риг.

Единицы: метры. Высота корпуса около 5,7 м с антеннами. Ось вверх +Z, вперёд -Y. Материалы встроены, внешних текстур нет. GLB не создаются. Открывайте `.blend` непосредственно в Blender либо через кнопку открытия файла общего просмотрщика.

## Проверка и воспроизведение

Запуск из корня репозитория: `blender --background --python Projects/MechaFighter/AnimeKnightmare/Tools/build.py`. Полная генерация предназначена для первоначального создания набора; последующие изменения выполняются только для затронутых деталей и сборок.

Детали проверяются перед сборкой: замкнутость каждой оболочки, положительный объём и отсутствие вырожденных граней. `part-validation.json` содержит результаты. Панели и корпуса намеренно состоят из отдельных соприкасающихся и местами перекрывающихся оболочек: автоматическая проверка всех межобъектных пересечений не выполняется.

Повторное открытие сохранённых моделей: `blender --background --python Projects/MechaFighter/AnimeKnightmare/Tools/verify.py`. Результаты: `reopen-validation.json`. Предпросмотры служат для проверки силуэта и сборки в исходной позе. Крайние позы и движение не проверены, поскольку анимации пока отсутствуют. Это проверка Blender-исходников, не игровая приёмка.

Для обновления только сборок без записи библиотек деталей задайте `MF_ASSEMBLIES_ONLY=1`. Список изменённых сборок задаётся через `MF_ONLY=MF-01_Aureole,MF-02_Kurenai`. Изменённую геометрию детали необходимо отдельно сохранить и проверить до обновления её экземпляров; параметры выше предназначены для изменений расположения и оснащения сборок.
