# Снайперская рельсовая турель

Каталог: sniper-turret, 1x2 клетки, один физический снаряд/ствол; сектор yaw 90°, скорость 45°/с. Размеры модели в design_unit, +Z вверх, -Y вперёд, клетки не приравниваются к метрам. Стиль ChunkyModular, тяжёлая сталь, повреждённая оранжевая краска; без надписей. Плотные скругления 8 сегментов, цилиндры 96.

| Требуется | Сравнение | Решение |
| --- | --- | --- |
| Узкая силовая станина | cm-deck рассчитан на широкую квадратную CM-T01; не подходит без деформации | Новая cm-sniper-bed |
| Поворотный погон | cm-bearing v2 имеет подходящие логические оси и стальной материал | Повторное использование v2, uniform scale 0.55 |
| Казённик и люлька | cm-receiver слишком широк и двухканален | Новая cm-sniper-breech |
| Рельсовой ускоритель | cm-barrel баллистический трубчатый; нужен иной силуэт и длинные открытые рельсы | Новая cm-sniper-rails |
| Блок накопителей | Подходящего силового накопителя нет | Новая cm-sniper-capacitor |
| Прицел | Подходящего длинного оптического прибора нет | Новая cm-sniper-sight |
| Статус | cm-lamp v2 подходит в уменьшенном равномерном масштабе | Повторное использование v2 |

Каждая новая деталь создаётся и текстурируется отдельно до сборки. Затем блок собирается экземплярами с отдельными ID и локальными трансформациями. Крепления и дульная точка являются логическими узлами. Поворот yaw ограничен -45..45°, авторская анимация подъёма и отката не изменяет игровые параметры. Исходники .blend, производные .glb. Промежуточные изображения и рендеры не создаются по просьбе пользователя. Игровой импорт и коллайдеры не заявляются.
