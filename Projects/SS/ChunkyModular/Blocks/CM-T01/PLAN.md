# CM-T01 — план ревизии 2

Пользователь отклонил пластиковый вид и прежнюю cm-handle. Требования: брутальный металл, отсутствие надписей, более массивная турель и больше разных самостоятельных деталей. Высокополигональные скругления сохраняются, радиус структурных фасок уменьшается.

Предыдущая версия полностью сохранена в `../../Revisions/CM-T01-v1.0.0.zip`. Прежние 12 типов деталей используются как основа ревизии 2.0.0; их геометрия и материалы обновляются явно. Новые детали также получают версию 2.0.0. До готовности отдельных исходников, материалов, метаданных и предпросмотров сборку не обновлять.

| Деталь | Решение |
| --- | --- |
| cm-deck, cm-foot, cm-bearing, cm-yoke | Увеличить опорные объёмы и заменить материалы. |
| cm-receiver, cm-cheek-left, cm-cheek-right | Расширить корпус и утолщить броню, убрать все надписи. |
| cm-barrel | Утолщить ствольный модуль, сохранить полый дульный срез. |
| cm-trunnion, cm-lamp, cm-radiator | Переработать отделку; прежнюю круглую крышку оставить как самостоятельный вариант. |
| cm-handle | Полностью заменить: цельная кованая скоба, широкие лапы, крепёж и косынки. |
| cm-handle-folding | Новая: складная скоба с отдельным шарниром и демонстрацией складывания. |
| cm-lifting-eye | Новая: подъёмная проушина с отверстием и усиленным основанием. |
| cm-shackle | Новая: такелажный шакл со съёмным пальцем. |
| cm-armor-slab | Новая: толстая бронеплита со скосами и открытыми кромками. |
| cm-vent-cassette | Новая: вентиляционная кассета с наклонными ламелями. |
| cm-fastener-cluster | Новая: силовая соединительная пластина с шайбами, гайками и шпильками. |
| cm-hydraulic-actuator | Новая: гидроцилиндр со штоком, проушинами и портами. |
| cm-cable-conduit | Новая: защищённый кабельный ввод с хомутами. |
| cm-muzzle-brake | Новая: дульная насадка; боковые углубления художественные, не сквозные каналы. |
| cm-breech-collar | Новая: разъёмная усилительная муфта ствола. |
| cm-access-hatch | Новая: сервисный люк с рамой, прокладкой, петлями и утопленной защёлкой. |
| cm-trunnion-armored | Новая: массивная восьмигранная крышка оси с утопленной индикацией. |

Всего 24 типа деталей. Все создаются и текстурируются отдельно. В CM-T01 используются 22 экземпляра: исходный состав, новая бронекрышка оси вместо прежней, люк и две ствольные муфты. Остальные новые детали остаются самостоятельной библиотекой для следующих блоков; не загромождать ими турель без функциональной причины.

Материалы: матовая повреждённая краска поверх стали, тёмный конструкционный металл, светлые обработанные поверхности, резина и сварные швы. Карты albedo / roughness / metallic / normal разделены по материалам. Надписей, логотипов и буквенных декалей на моделях нет.

Координаты и неопределённый игровой масштаб сохраняются: +Z вверх, -Y вперёд, условные единицы модели. Каталог и игровой баланс не изменяются.

Дополнение пользователя: cm-barrel сделать длиннее и агрессивнее, cm-receiver — больше. Выполнено: длина отдельного ствола по габаритам выросла с 2.0975 до 3.48 единицы (около 66%), добавлена восьмигранная насадка с настоящими боковыми вырезами. Габариты казённого корпуса выросли на 30% по ширине и глубине и на 20% по высоте. Ствольные муфты являются дочерними экземплярами стволов и движутся вместе с отдачей.
