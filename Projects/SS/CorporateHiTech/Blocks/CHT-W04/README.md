# CHT-W04 — Assault — широкий штурмовой дробовик

Финальный корпоративный вариант: белые гранёные бронепанели, небольшие фаски, голубые полосы эмиссии. Низкий широкий корпус с разнесёнными бронекрыльями и одним крупным коротким дульным отверстием.

Каталог fleet-shotgun-assault: 2×2 клетки, 1 ствол, 360° наведение, 180°/с. Восемь дробин за выстрел из одного ствола, а не восемь стволов.

Состав: неизменные CHT-P01/P02 1.1.0 и четыре новые самостоятельные детали CHT-W04-HULL, -BARREL, -SIDE, -SIGHT (актуальные версии указаны в assembly.json). Их part.json содержат геометрию, материалы, эмиссию, logical sockets и функциональные дульные точки. assembly.json хранит экземпляры и вращение вокруг Z. Новый head-in явно совместим с интерфейсом CHT-P03.base без правки общей детали.

Условные model-unit не считаются метрами/клетками. Визуальная длина стволов отличается от ShootPosition каталога; значения gameplay хранятся в полном catalogSnapshot без изменения баланса. Источники редактируемы; производные экспорты размещает общий просмотрщик в Exports/. Нет игровых коллайдеров, LOD или установки в игру. Промежуточные варианты, HTML и отдельный просмотрщик не создавались.

Редакция 1.1.0: доминирующие коробчатые формы заменены функциональными профилями. Один большой круглый открытый канал с коническим переходом и металлическим чоком; широкие плавно профилированные плечи со сквозными вентиляционными щелями. Компоновка, палитра, точки крепления, число каналов и наведение сохранены. Предыдущие JSON архивированы в Versions/1.0.0.json, альтернативные зарегистрированные блоки и отдельные превью не создавались.
