# План состава CHT-W04

Каталог: fleet-shotgun-assault, сетка 2×2 клетки; клетки не метры и не граница меша. 1 ствол; дуга 360°, скорость 180°/с.

| Деталь | Решение | Совместимость и причина |
|---|---|---|
| CHT-P01 1.1.0 | Повторно использовать | Гранёное основание и bearing подходят; масштаб 1 |
| CHT-P02 1.1.0 | Повторно использовать | Поворотный узел, base к P01.bearing; head к интерфейсу P03.base |
| CHT-W04-HULL | Создать новую | Корпус с интерфейсом P03.base и характерным силуэтом этого оружия |
| CHT-W04-BARREL | Создать новую | Открытый гранёный канал, functionalPoint muzzle; число экземпляров по CSV |
| CHT-W04-SIDE | Создать новую | Отдельная боковая броня/подача, не соответствует старым узким щекам P04 |
| CHT-W04-SIGHT | Создать новую | Отдельная низкая оптика, привязка к собственному корпусу |

Сначала закончить четыре детали каждого блока, затем собрать экземпляры. Общие материалы неизменны; процедурное PBR и геометрическая эмиссия. Внешние стили и проекты не использовать. Промежуточные модели/HTML/превью по запросу пользователя не создавать.

## Редакция форм 1.1.0

Варианты существующих собственных деталей: lathe с замкнутым кольцевым профилем для настоящих открытых каналов и конических переходов; profile для арочных/плавных силовых оболочек. Точки крепления и единичный масштаб сохранены. P01/P02 неизменны. Геометрия заменяет старые коробки, а не добавляет случайный декор.
