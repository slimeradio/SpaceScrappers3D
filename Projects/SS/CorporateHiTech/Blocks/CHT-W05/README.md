# CHT-W05 — Bastion / четырёхкассетная ракетная башня

Широкая приземистая установка: четыре открытых квадратных ракетных канала, независимые бронекассеты, высокий центральный датчик и задняя силовая гребёнка. Ровно четыре функциональных дульных точки; видимые ракеты — декоративные заполнители. SeekMissile, урон 850, дальность 420 — исходные значения каталога, без пересчёта в DPS.

Каталог: `fleet-rocket-bastion`, сетка 3x3 клеток; клетки не метры. Дуга 360°, скорость 45°/с. Исходная геометрия в Parts/*/part.json; сборка в assembly.json. Основание неподвижно; yaw вращает все дочерние узлы. Масштаб экземпляров единичный.

Детали: CHT-W05-BASE, CHT-W05-CASSETTE, CHT-W05-POWER, CHT-W05-SENSOR, CHT-W05-YAW.

Белая многослойная броня, тёмные технологические швы, голубая эмиссия, процедурное покрытие. Существующий просмотрщик поддерживает SharedTextures. Игровой баланс не изменяется. Это авторский ассет, не игровой формат; коллайдеры и LOD не заданы каталогом. Производные экспорты хранятся отдельно в Exports/.

Обновление формы 1.1.0: Цилиндрические ракеты с коническими головными частями в прежних четырёх квадратных кассетах. Профилированный кольцевой подшипник опоры. Состав и крепления сохранены; новые формы заменяют прежние доминирующие объёмы.
