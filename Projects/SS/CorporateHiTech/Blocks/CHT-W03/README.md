# CHT-W03 — Cyclone — двухканальный скорострельный пулемёт

Финальный корпоративный вариант: белые гранёные бронепанели, небольшие фаски, голубые полосы эмиссии. Длинный узкий двухканальный узел с продольными рельсами и отдельными кассетами подачи.

Каталог fleet-minigun-cyclone: 2×2 клетки, 2 ствола, 360° наведение, 240°/с. Имя minigun не означает шесть выдуманных стволов: каталог содержит ровно два независимых канала.

Состав: неизменные CHT-P01/P02 1.1.0 и четыре новые самостоятельные детали CHT-W03-HULL, -BARREL, -SIDE, -SIGHT (актуальные версии указаны в assembly.json). Их part.json содержат геометрию, материалы, эмиссию, logical sockets и функциональные дульные точки. assembly.json хранит экземпляры и вращение вокруг Z. Новый head-in явно совместим с интерфейсом CHT-P03.base без правки общей детали.

Условные model-unit не считаются метрами/клетками. Визуальная длина стволов отличается от ShootPosition каталога; значения gameplay хранятся в полном catalogSnapshot без изменения баланса. Источники редактируемы; производные экспорты размещает общий просмотрщик в Exports/. Нет игровых коллайдеров, LOD или установки в игру. Промежуточные варианты, HTML и отдельный просмотрщик не создавались.

Редакция 1.1.0: доминирующие коробчатые формы заменены функциональными профилями. Два круглых открытых ствольных кожуха с коническими переходами; арочные кассеты со шпинделями подачи; сужающийся литой приёмник. Компоновка, палитра, точки крепления, число каналов и наведение сохранены. Предыдущие JSON архивированы в Versions/1.0.0.json, альтернативные зарегистрированные блоки и отдельные превью не создавались.
