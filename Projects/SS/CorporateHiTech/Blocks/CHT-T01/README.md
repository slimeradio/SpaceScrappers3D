# CHT-T01 / Aster Twin

Версия 1.1.0: угловатая переработка по запросу пользователя. Восьмигранное основание, наклонные составные панели корпуса, ступенчатые боковины с жабрами, шестигранные эмиттеры с прямоугольной оптикой. Новая форма построена из 117 геометрических элементов семи переиспользуемых деталей. Скругления оставлены только на небольших кромках; круглый подшипник находится внутри гранёного основания. Предыдущие параметрические источники сохранены в Parts/*/Versions/1.0.0.json и Versions/1.0.0.json.

Тестовая двухствольная лазерная турель, корпоративный Hi-Tech. Каталожный ID: fleet-laser-twin; сетка 2×2, круговое наведение 360°, скорость 120°/с, два эмиттера. Игровой баланс не менялся.

Открыть viewer.html через Tools/serve.ps1. Перетаскивание — орбита, колесо — масштаб. Доступны вид сверху, разборка, выбор отдельных деталей и вращение турели. Точная геометрия создаётся из Parts/*/part.json; сборка и стабильные ссылки — assembly.json. Изменить параметры детали и перезагрузить просмотр. Два эмиттера и две боковины — экземпляры общих деталей, не копии геометрии исходника.

Состав: 7 самостоятельных деталей, 9 экземпляров. P01 платформа; P02 подшипник; P03 корпус; P04 боковая капсула ×2; P05 эмиттер ×2; P06 визир; P07 сервисная крышка. Принятые материалы и процедурное текстурирование — Materials/materials.json. Голубая эмиссия выполнена геометрическими вставками; файловых текстур нет.

Поворот вокруг +Z на подшипнике; весь верх следует за yaw. Наклон и отдача не добавлены: каталог их не задаёт. Дульные точки находятся в локальных данных P05. Каталожные позиции стволов ±0.254 по X соблюдены; визуальная дульная точка вынесена на 0.031 model-unit относительно каталожного Y=1.55. Масштаб клетки в метрах неизвестен; соответствие реальному коллайдеру не подтверждено. Габариты меша не равны размеру сетки.

Редактируемый источник: part.json + assembly.json + Tools/model.js. Производный экспорт: Exports/CHT-T01.gltf (PBR, эмиссия, иерархия и анимация yaw). Предпросмотры в Previews/, отдельные детали в Parts/*/Previews/. Статический glTF и авторские метаданные не являются игровым интеграционным форматом. LOD и игровые коллайдеры не создавались; в игре не проверено.

Выбор SharedTextures: кнопка «Текстуры» открывает каталог 106 цветовых карт из CarbonFibre, CleanVersion, Concrete, Hazard и HeavyRust. Доступны фильтр, поиск, отдельные назначения для armor / edge / graphite / rubber, масштаб, сила рельефа, инверсия Y нормалей и возврат к исходному материалу. Выбор сохраняется в localStorage этого браузера и применяется также при просмотре отдельных деталей. Это настройка просмотра, part.json и штатный glTF на диске она не перезаписывает. Вызов exportGLTF экспортирует текущее отображение с выбранными картами.

Общая папка SharedTextures подключена по прямому запросу пользователя. Исходные DDS не меняются. Производные PNG до 1024px и миниатюры хранятся в Materials/SharedTexturesPreview; Tools/prepare_shared_textures.py обновляет их и каталог. В браузере используются RGB из _cm, RGB нормали из парного _ng и приближённая roughness = 1 − alpha(_ng). Alpha(_cm), _add и оригинальный игровой шейдер не воспроизводятся. Это PBR-предпросмотр, не точное воспроизведение исходного шейдера. Карты цвета — sRGB, нормали и roughness — линейные данные. Для всех мешей, включая loft, добавлена коробочная UV-проекция в модельных единицах. Она предназначена для просмотра; размещение конкретных элементов игровых атласов требует отдельной UV-развёртки. Эмиссия cyan / glass не затрагивается.
