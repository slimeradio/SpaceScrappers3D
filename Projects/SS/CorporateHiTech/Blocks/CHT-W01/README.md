# CHT-W01 — Citadel — крейсерская артиллерия

Финальная параметрическая сборка assembly.json. Каталог fleet-artillery-cruiser; два независимых артиллерийских ствола, сетка 3×4, полный круг 360°, 45°/с (8 секунд).

Четыре новые переиспользуемые детали 1.0.0: CHT-W01-BASE, CHT-W01-HEAD, CHT-W01-BARREL, CHT-W01-PACK. Белая многослойная броня, графитовые зазоры, голубые эмиссивные каналы, металлические направляющие. Все детали имеют материалы, ограничение масштаба, сокеты; дульная точка хранится в BARREL. Сборка и сокеты совпадают в исходной позе; дочерние элементы следуют за yaw. Самостоятельных анимаций деталей нет.

Правая система координат, +Z вверх, +Y вперёд. Model units — условные авторские единицы, не метры; игровые клетки не задают размер меша. Стволы намеренно визуально удлинены; X артиллерии ±0.254 сохранены, визуальная координата дул по Y отличается от каталога. Игровую интеграцию и mapping координат нужно выполнить отдельно. LOD и игровые коллайдеры в задачу не включены. Промежуточных кандидатов, отдельного просмотрщика и preview-файлов не создавалось; экспорт выполняется общим инструментом.


## Ревизия форм 1.1.0

Профилированные полые артиллерийские стволы, конические казённики и дульные тормоза заменили прямоугольные кожухи. Литой клиновидный перед башни и цапфы связывают новую геометрию с назначением. Общая компоновка, палитра, количество стволов, сокеты, дульные точки и наведение сохранены. Прежние редактируемые JSON находятся в Versions/1.0.0.json соответствующих папок. Источник ревизии Tools/revise_forms_w01_w02.py применяется поверх версии1.0.0; новых вариантов блоков и просмотрщиков нет.
