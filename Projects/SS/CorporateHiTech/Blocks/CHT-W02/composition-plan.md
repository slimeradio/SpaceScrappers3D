# План состава CHT-W02

Каталог: sniper-turret; 1×2 клетки, один ствол, 90°, 45°/с. Клетки не трактуются как метры.

Проверены CHT-P01–P07 версии 1.1.0: их размеры, короткие лазерные кожухи, ширина корпуса и крепления не подходят выбранному силуэту. Новые BASE (палубная платформа), HEAD (поворотный бронекорпус), BARREL (артиллерийский ствол / двухрельсовый ускоритель), PACK (казённый модуль / конденсатор) — отдельные детали 1.0.0. Материалы существующей библиотеки используются повторно. Деталь BARREL содержит две рельсы одного ствола. Сначала создаются детали, затем сборка. Общие детали не меняются.


## Ревизия форм 1.1.0

HEAD, BARREL и PACK заменены параметрическими формами версии1.1.0: клин, рамы с окнами, конденсаторы. BASE повторно используется1.0.0. Крепления и масштаб совместимы, материалов извне нет.
