# CHT-W02 — Needle — снайперская рельсовая турель

Финальная параметрическая сборка assembly.json. Каталог sniper-turret; один ствол из двух рельсовых направляющих, сетка 1×2, сектор −45…45°, 45°/с (2 секунды).

Четыре новые переиспользуемые детали 1.0.0: CHT-W02-BASE, CHT-W02-HEAD, CHT-W02-BARREL, CHT-W02-PACK. Белая многослойная броня, графитовые зазоры, голубые эмиссивные каналы, металлические направляющие. Все детали имеют материалы, ограничение масштаба, сокеты; дульная точка хранится в BARREL. Сборка и сокеты совпадают в исходной позе; дочерние элементы следуют за yaw. Самостоятельных анимаций деталей нет.

Правая система координат, +Z вверх, +Y вперёд. Model units — условные авторские единицы, не метры; игровые клетки не задают размер меша. Стволы намеренно визуально удлинены; X артиллерии ±0.254 сохранены, визуальная координата дул по Y отличается от каталога. Игровую интеграцию и mapping координат нужно выполнить отдельно. LOD и игровые коллайдеры в задачу не включены. Промежуточных кандидатов, отдельного просмотрщика и preview-файлов не создавалось; экспорт выполняется общим инструментом.


## Ревизия форм 1.1.0

Главные новые формы: стреловидный несущий клин, открытые натяжные рамы рельсов с окнами и цилиндрические конденсаторы вместо коробчатой кассеты. Общая компоновка, палитра, количество стволов, сокеты, дульные точки и наведение сохранены. Прежние редактируемые JSON находятся в Versions/1.0.0.json соответствующих папок. Источник ревизии Tools/revise_forms_w01_w02.py применяется поверх версии1.0.0; новых вариантов блоков и просмотрщиков нет.
