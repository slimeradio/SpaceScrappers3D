# CHT-W01-PACK — Кассета управления огнём

Редактируемый источник: part.json, версия 1.0.0. +Z вверх, +Y вперёд; условные единицы. Положительный единичный масштаб. Материалы общей библиотеки: armor, cyan, edge, glass, graphite, rubber. Процедурное гладкое PBR-покрытие, проекция по коробке; файловых текстур нет. Голубая эмиссия обозначена отдельными геометрическими поверхностями. Крепления и функциональные ориентиры сохранены в JSON. Собственных анимаций нет.
