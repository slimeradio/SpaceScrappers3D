# CHT-W05-CASSETTE — Bastion: одиночная открытая ракетная кассета

Редактируемая параметрическая деталь 1.1.0. +Z вверх, +Y вперёд, model-unit, единичный масштаб. Материалы: armor, cyan, edge, graphite, rubber. Процедурный PBR, растровых зависимостей нет; SharedTextures назначаются в общем просмотрщике. Голубые области имеют эмиссию из общей библиотеки. Крепления и функциональные точки находятся в part.json; логические маркеры не являются мешами. Самостоятельной анимации нет.

Изменение формы 1.1.0: Прямоугольная пусковая кассета сохранена. Внутри — цилиндрическая ракета с профилированным коническим носом; квадратная декоративная ракета удалена. Исходник 1.0.0 сохранён в Versions/1.0.0.json.
