# CHT-W04-HULL — Assault: широкий низкий корпус

Версия 1.0.0. Редактируемая параметрическая геометрия: part.json. +Z вверх, +Y вперёд, правая система, model-unit (не метры). Единичный масштаб.

Белое процедурное покрытие armor, тёмная механика graphite/rubber, металлические кромки edge и отдельные голубые emissive-полосы cyan (2.5). Исходные растровые карты не нужны; выбор SharedTextures доступен в общем просмотрщике. Логические sockets и functionalPoints не входят в видимую геометрию. Самостоятельных анимаций нет.
