# CHT-W04-BARREL — Assault: единый широкий канал

Версия 1.1.0. Один настоящий круглый раскрытый канал с коническим кожухом, открытым металлическим чоком и глубокой внутренней стенкой заменяет сегментную коробчатую раму.

Исходник part.json: правая система, +Y вперёд, +Z вверх, model-unit, единичный масштаб. Сохранены все sockets, направления и функциональные точки. Параметрические lathe/profile/loft являются редактируемой геометрией. Белое покрытие armor, graphite/rubber механика, edge кромки, cyan эмиссия 2.5. Процедурное PBR, SharedTextures через общий просмотрщик; исходных растровых карт нет. Самостоятельных анимаций нет. Предыдущий JSON в Versions/1.0.0.json — архив, не альтернативный блок.
