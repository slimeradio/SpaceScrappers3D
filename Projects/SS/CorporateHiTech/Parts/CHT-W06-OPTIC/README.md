# CHT-W06-OPTIC — Helion: один мощный непрерывный излучатель

Редактируемая параметрическая деталь 1.1.0. +Z вверх, +Y вперёд, model-unit, единичный масштаб. Материалы: armor, cyan, edge, glass, graphite. Процедурный PBR, растровых зависимостей нет; SharedTextures назначаются в общем просмотрщике. Голубые области имеют эмиссию из общей библиотеки. Крепления и функциональные точки находятся в part.json; логические маркеры не являются мешами. Самостоятельной анимации нет.

Изменение формы 1.1.0: Коробчатая оптика полностью заменена полым коническим кожухом вращения, круглым металлическим ободом и выпуклой линзой. Один функциональный луч сохранён, muzzle перед центром линзы. Исходник 1.0.0 сохранён в Versions/1.0.0.json.
