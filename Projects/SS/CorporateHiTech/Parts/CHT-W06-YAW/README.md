# CHT-W06-YAW — Helion: длинный силовой позвоночник

Редактируемая параметрическая деталь 1.0.0. +Z вверх, +Y вперёд, model-unit, единичный масштаб. Материалы: armor, cyan, edge, graphite. Процедурный PBR, растровых зависимостей нет; SharedTextures назначаются в общем просмотрщике. Голубые области имеют эмиссию из общей библиотеки. Крепления и функциональные точки находятся в part.json; логические маркеры не являются мешами. Самостоятельной анимации нет.
