# CHT-W01-BARREL — Длинный артиллерийский ствол с дульным тормозом

Версия 1.1.0. Прежние прямоугольные казённик и ствол заменены профилированными телами вращения: коническая переходная часть, длинная труба, ступенчатый дульный тормоз и открытый сквозной канал радиуса .047–.049. Дульная точка [0,1.654,0] сохранена; внутренних чёрных заглушек нет.

Редактируемый источник part.json; прежний источник Versions/1.0.0.json. Материалы прежней общей библиотеки, процедурное PBR и голубая эмиссия, отдельные растровые текстуры не используются. Правая система координат, +Z вверх, +Y вперёд, model units; масштаб 1. Сокеты, локальные оси, функциональные точки сохранены. Самостоятельных анимаций нет.
