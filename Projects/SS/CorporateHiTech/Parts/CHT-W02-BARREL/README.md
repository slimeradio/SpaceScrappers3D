# CHT-W02-BARREL — Один ускоритель с двумя разделёнными рельсами

Версия 1.1.0. Внешние прямоугольные кожухи и повторяющиеся коробки заменены двумя открытыми натяжными рамами с большими сквозными окнами; плоские контактные рельсы и центральный свободный канал сохранены. Опоры — гранёные катушки. Это один ускоритель с двумя направляющими, не два ствола. Дульная точка сохранена.

Редактируемый источник part.json; прежний источник Versions/1.0.0.json. Материалы прежней общей библиотеки, процедурное PBR и голубая эмиссия, отдельные растровые текстуры не используются. Правая система координат, +Z вверх, +Y вперёд, model units; масштаб 1. Сокеты, локальные оси, функциональные точки сохранены. Самостоятельных анимаций нет.
