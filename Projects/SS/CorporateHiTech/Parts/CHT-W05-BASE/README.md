# CHT-W05-BASE — Bastion: широкая опорная палуба

Редактируемая параметрическая деталь 1.1.0. +Z вверх, +Y вперёд, model-unit, единичный масштаб. Материалы: armor, cyan, edge, graphite. Процедурный PBR, растровых зависимостей нет; SharedTextures назначаются в общем просмотрщике. Голубые области имеют эмиссию из общей библиотеки. Крепления и функциональные точки находятся в part.json; логические маркеры не являются мешами. Самостоятельной анимации нет.

Изменение формы 1.1.0: Опорный подшипник заменён настоящим кольцевым профилем вращения с наклонным буртом; палуба сохранена. Исходник 1.0.0 сохранён в Versions/1.0.0.json.
