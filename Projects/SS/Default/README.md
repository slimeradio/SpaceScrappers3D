# SS / Default

Проект: `SS` — 3D-модели блоков игры SpaceScrappers.
Стиль: `Default`.
Корень контекста: `Projects/SS/Default/`.

## Цель

Создать красиво выполненные 3D-модели всех блоков игры. Разработать библиотеку деталей и наборов, из которых можно собирать разные блоки с согласованной формой, материалами и детализацией.

## Организация

| Папка | Содержимое |
| --- | --- |
| `Parts/` | Исходники отдельных переиспользуемых деталей. |
| `Kits/` | Наборы совместимых деталей и правила их сборки. |
| `Blocks/` | Исходники готовых моделей блоков, собранных из деталей и наборов. |
| `Materials/` | Материалы и палитра этого стиля. |
| `References/` | Референсы и требования, явно выбранные для SS / Default. |
| `Exports/` | Производные модели для игры и материалы предпросмотра. |

## Принципы моделирования

- Сохранять редактируемые геометрические исходники; по возможности использовать параметры, кривые и поверхности.
- Повторяющиеся элементы оформлять отдельными деталями. Наборы объединяют совместимые детали для сборки блоков.
- В описании каждого набора и блока указывать используемые детали, чтобы зависимости были явными.
- После выбора масштаба, осей и правил соединения применять их согласованно ко всем моделям этого стиля.
- Исходники и производные экспорты хранить раздельно.
- Использовать только контекст SS / Default. Материалы других проектов и стилей подключать по прямому указанию пользователя.

## Пока не определено

Художественное направление Default, первый блок для моделирования, инструменты и форматы, единицы измерения, оси, размеры модулей и требования игрового экспорта будут определены отдельно. Название Default пока обозначает первый стиль и не задаёт его внешний вид.

Сейчас создана структура проекта; модели и наборы ещё не созданы.
