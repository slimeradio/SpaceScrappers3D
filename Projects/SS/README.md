# SS — модели блоков SpaceScrappers

## Общий каталог

[Catalog/blocks.csv](Catalog/blocks.csv) — единый изменяемый список блоков для всех визуальных стилей проекта SS. Исходный файл пользователя: `SpaceScrappers-blocks-full-2026-10-16.csv`, дата среза — 2026-10-16. Каталог содержит 125 блоков с уникальными ID: 59 игровых XML-определений и 66 визуальных заготовок без игрового XML. Поля `Статус` и `Семейство_каталога` различают состояние и семейство блоков.

Каталог будет пополняться и изменяться. Обновлять его следует централизованно, сохраняя исходные поля и ID существующих блоков, пока пользователь явно не задаст их изменение. Не создавать отдельные копии каталога для стилей. Количество блоков выше описывает текущий срез, а не ограничение проекта.

Размеры, назначение и ограничения в CSV — общие исходные данные для моделей. Они не подтверждают актуальность исходного кода игры: приложенный CSV является срезом, его происхождение и ограничения указаны в самих строках. Пути к XML являются справочными и не разрешают автоматически подключать внешний репозиторий.

Каталог задаёт конечный охват работ и сам по себе не означает, что модели уже созданы или что их нужно немедленно создавать. При изменении каталога соответствие моделей проверяется отдельно внутри каждого стиля.

## Границы контекста

`Catalog/` — общие данные проекта SS, а не визуальный стиль. Этот README и каталог доступны всем стилям SS. Художественные решения, референсы, детали, наборы, материалы и модели каждого стиля остаются внутри его собственной папки. Общий список блоков не разрешает переносить визуальный контекст между стилями или проектами.
