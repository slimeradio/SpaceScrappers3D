# MA-W08-P02 v1.0

Single open polygonal rocket launch canister. Редактируемый самостоятельный источник. Геометрия проверена до сборки; geometry-validation.json. Крепления, PBR и эмиссия в part.json; без файловых текстур/UV. Статичная деталь, BU условные, единичный масштаб; без GLB. Previews/top.png и perspective.png.
