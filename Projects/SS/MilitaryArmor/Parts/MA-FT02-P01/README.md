# MA-FT02-P01 v1.0

Парные опоры ёмкостей с защищённым коллектором. Самостоятельный редактируемый Blender, процедурные PBR-материалы из part.json; без файловых текстур и UV, эмиссия отсутствует. Полные логические sockets и области, unit scale, статическая модель. Геометрический gate немедленно до сборки: geometry-validation.json; отдельные top/perspective PNG. GLB не создавался.
