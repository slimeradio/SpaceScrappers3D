# MA-H-AN1-P01 v3.0

Шарнирная половина радиаторной секции. Две тепловые поверхности, узкие защитные рёбра и ось Y; открыта при 0°, закрыта при −90°. Крепление root в начале оси. Тепловая эмиссия назначается независимо на уровне экземпляра. Геометрия проверена до сборки, исходник редактируемый, BU условные, без GLB.
