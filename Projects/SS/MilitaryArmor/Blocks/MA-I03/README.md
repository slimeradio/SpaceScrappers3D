# MA-I03 — грузовой контейнер 3×3

Широкий цельный грузовой объём со ступенчатой крышей, центральной полосой из трёх загрузочных люков, боковыми диагональными контрфорсами и наружными направляющими. Семейство MA-I01/MA-I02, без батарейных кассет и универсальной сервисной крышки.

6 экземпляров, 3 уникальных источника: новый MA-I03-P01 v1.0 и повторно используемые MA-I01-R2-P02/P03 v2.0 без изменений/масштаба. composition-plan.md; MA-I03.blend; assembly.json; validation.json. Previews: top.png, perspective.png, top-grayscale.png.

Статическая визуальная заготовка каталога cargo-3x3 без игрового XML; вместимость и механика не заданы. Условные BU, сетка не метры. Процедурные PBR, без файловых текстур/UV; ограниченная эмиссия только в готовых индексах люков. GLB нет, игровой интеграции нет.

## Состояния — текущая редакция

Прежние замечания о статике/отсутствии анимаций выше относятся к сохранённой версии до этой правки. Текущий Blender-исходник содержит независимые контролы, управляемые материалы и сохранённые Actions: state-authoring.json. Выбрать объект MA-I03 → Custom Properties; Actions доступны в Action Editor, по умолчанию не назначены. Нагрев/заполнение не сбрасываются отключением. Геометрия неизменённых деталей не пересоздавалась, старые исходники — Versions/StateAnimation-before. Старый validation.json — историческая проверка; новые результаты в state-validation.json. Игровой интеграции и новых GLB нет.
