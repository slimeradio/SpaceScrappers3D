# MA-I03 — план состава до моделирования

Каталог cargo-3x3, грузовой контейнер 3×3; визуальная заготовка без игрового XML. Вместимость и механизмы не заданы. Семья цельных контейнеров MA-I01 v2 / MA-I02: широкие загрузочные люки, грузовые направляющие и силовые рёбра. Новый вариант отличается широким ступенчатым объёмом, тремя загрузочными секциями вдоль центральной полосы и парными диагональными контрфорсами по бортам. Это не масштабированная копия 2×2.

Повторно использовать MA-I01-R2-P02 v2.0: 3 готовых люка 2.87×1.29 BU без масштаба; расстояние между люками 0.36 BU, уплотнения и силовые разделители разнесены. Повторно использовать MA-I01-R2-P03 v2.0: две направляющие длиной 3.87 BU у торцов без масштаба. Корпуса MA-I01-R2-P01 и MA-I02-P01 не подходят размером и посадками: создать один MA-I03-P01, новый корпус 5.48×5.38 BU. Батарейные детали и сервисный восьмигранник не использовать.

Координаты: правая система, +Z вверх, -Y вперёд; BU не метры, размер сетки не физический масштаб. Сначала standalone source и геометрический gate, затем экземпляры сохранённых источников. Статический source-only Blender; GLB не создавать.
