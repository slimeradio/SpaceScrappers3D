# MA-W05 — Fleet fan

Wide fan-shaped scatter turret. One physical muzzle aperture, twelve projectiles per shot in catalog; the seven diagnostic field tiles are not barrels.

Editable source: MA-W05.blend. Derived viewer export: Exports/MA-W05.glb. Four new independent source parts MA-W05-P01..P04; MA-P06/MA-P07 1.3 reused at unit scale. Details and attachment plan: composition-plan.md.

Animation: yaw 360 degrees, enclosed elevation and recoil. Elevation/recoil are visual demonstrations. BU physical scale, colliders, LOD and engine integration remain unspecified. Final Blender source and GLB are validated; no game installation performed.
