# MA-E01 — средний двигатель

Каталог thruster-med, 1×2, один источник тяги. Вытянутый силовой кожух, крупное полое сопло и боковые термопанели.

Состав до моделирования: MA-E01-P01 новая несущая кассета; MA-E01-P02 новая камера; MA-E01-P03 новый большой вариант сопла; MA-E01-P04 новая термопанель (два повёрнутых экземпляра). MA-E01-P05 новый компактный сервисный картридж: готовый MA-P06 версии1.3 не подходит по ширине, масштабирование не используется. Детали оружия и брони по геометрии/интерфейсам не заменяют камеру и сопло.

Все экземпляры единичного масштаба, +Z вверх, -Y выход струи, +Y тяга. BU условные; игровые размеры и сила не пересчитываются. Неподвижная конструкция, без выдуманных клипов и постоянного пламени.

Финальные файлы: MA-E01.blend, Exports/MA-E01.glb. Состав — assembly.json, проверка — validation.json. Материалы процедурные PBR: Armor/Ceramic/Titanium/Dark и ограниченная бирюзовая эмиссия в горловине/диагностике. Файловых текстур нет. Собственные детали сохранены отдельно; Оба двигателя используют общий компактный картридж MA-E01-P05; прежние исходники не изменены. GLB — для просмотра, без установки в игру.

## Состояния — текущая редакция

Прежние замечания о статике/отсутствии анимаций выше относятся к сохранённой версии до этой правки. Текущий Blender-исходник содержит независимые контролы, управляемые материалы и сохранённые Actions: state-authoring.json. Выбрать объект MA-E01 → Custom Properties; Actions доступны в Action Editor, по умолчанию не назначены. Нагрев/заполнение не сбрасываются отключением. Геометрия неизменённых деталей не пересоздавалась, старые исходники — Versions/StateAnimation-before. Старый validation.json — историческая проверка; новые результаты в state-validation.json. Игровой интеграции и новых GLB нет.
