# MA-F02 — Производственный блок базы 2×1, переделка v2.0

Семейная производственная линия MA-F01, собственная ступенчатая сервисная башня базы на задней стороне. Отличие не требует ломать узнаваемость производственного семейства.

Проверка библиотеки и решение ДО моделирования: Повторно использовать MA-F01-R2-P01/P02/P03 v2.0, единичный масштаб, те же socket poses. MA-F02-P01 v1.0 — низкий закрытый service bay; по силуэту не подходит. Создать MA-F02-R2-P01 ступенчатый сервисный узел с защищёнными подключениями. Базовая линия геометрически не пересобирается.

Оси +Z вверх, -Y вперёд, правая система. Все экземпляры в единичном масштабе. Новые детали проходят source/evaluated gate и сохраняются отдельно до сборки. Общий восьмигранный картридж не используется. GLB не создавать.
