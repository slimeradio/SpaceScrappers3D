# MA-FT01 — план состава до моделирования

Каталог: fuel-tank-1x2, бак топлива 1×2; visual only, без XML ёмкости и передачи. Правая система +Z вверх, -Y вперёд, условные BU. Масштаб экземпляров единичный.

| Требование | Проверено | Решение и причина |
|---|---|---|
| Узкая силовая рама | MA-F01-P01 v1.0 3.82×1.72, production sockets; MA-H01-P01 v1.0 плоская радиаторная рама | Создать MA-FT01-P01: ёмкость требует глубоких опор и закрытых торцевых интерфейсов; готовые рамы имеют другое назначение и места посадки |
| Одна продольная ёмкость | MA-B01-P02 v1.0 1.316×1.36×.849, ячейка батареи с эмиссией; MA-M02-P02 v1.0 оптический процессор | Создать MA-FT01-P02: не масштабировать несовместимые детали; замкнутый гранёный бак с суженными торцами |
| Силовой обруч | библиотека Parts, готовые thermal-панели MA-E01-P04 не являются охватывающими элементами | Создать MA-FT01-P03, повторить дважды без масштабирования |
| Сервисный интерфейс | MA-R01-P05 v1.0 .74×.60×.08, исправленная геометрия, service-cartridge.v1 | Повторно использовать без изменений; маленькая штатная диагностика допустима. Дефектный MA-P06 не использовать |

Новые детали сначала сохранить отдельно с материалами, полными sockets, previews и немедленным source/evaluated geometry gate. Затем собрать пять стабильных экземпляров, проверить четыре соединения, повторно открыть источники отдельным verifier. Никаких GLB или игровой интеграции.
