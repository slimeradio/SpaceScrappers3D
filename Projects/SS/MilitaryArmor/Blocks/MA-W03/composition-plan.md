# MA-W03 / Cyclone — состав до моделирования

Каталог: fleet-minigun-cyclone, 2x2 клетки; 2 игровых ствола. Клетки не преобразуются в метры. Авторинг BU, +Z вверх, -Y вперёд, масштаб экземпляров 1.

- MA-W03-P01 v1.0: новая трёхлучевая опорная платформа; MA-P01 слишком велик и имеет прямоугольную компоновку.
- MA-W03-P02 v1.0: новый узкий раздвоенный поворотный корпус, короткая силовая вилка.
- MA-W03-P03 v1.0: новый центральный узел возвышения с двумя роторными осевыми посадками.
- MA-W03-P04 v1.0: новый роторный ствол, два экземпляра. Один открытый функциональный канал на экземпляр, внешние рёбра не являются дополнительными стволами.
- MA-P06 v1.3: повторно использовать сервисный картридж без изменения/масштабирования.
- MA-P07 v1.3: повторно использовать лидар без изменения/масштабирования.

Роторы вращаются вокруг локальной Y, установка вокруг Z. Сдержанная бирюзовая индикация, светлые косые керамические пластины, закрытые механизмы. Только окончательные .blend и GLB, без пользовательских промежуточных вариантов. Экспорт — для просмотрщика, игровой интеграции нет.
