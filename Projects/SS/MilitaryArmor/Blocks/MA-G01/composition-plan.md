# План состава MA-G01 до моделирования

Каталог garage-ship: гараж 1×1, Capacity512 это вместимость, не количество кораблей. Масштаб кораблей неизвестен. Статический компактный узел.

| Требуется | Проверено | Решение |
|---|---|---|
| Доковая платформа | MA-N01-P01 v1.0 1.74×1.65 BU, MA-F01-P01 v1.0 3.82×1.72 BU | Новая MA-G01-P01: первая имеет электронную корону и антенные посадки, вторая двухместная; нужны передние направляющие |
| Портальная рама | MA-I01-P01 грузовая кассета, MA-I01-P02 плоский люк | Новая MA-G01-P02: утопленный вертикальный вход с силовой перемычкой, без деформации чужого люка |
| Задний кожух | MA-F01-P02, MA-B01-P02 | Новая MA-G01-P03: короткий корпус под портал и пониженная крыша |
| Диагностика | MA-R01-P05 v1.0 | Повторно использовать, штатный service-cartridge.v1, единичный масштаб |

Все детали проходят geometry gate отдельно до сборки. Статика, без новых анимаций, без GLB. Оси +Z вверх, -Y вперёд; BU условные.
