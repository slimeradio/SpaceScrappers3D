# MA-W09 — Турель-дробовик

Короткий широкий полый ствол с восьмигранным дульным поясом, массивная казённая часть, низкая люлька и один боковой магазин. Один физический ствол, 8 дробин по каталогу; размер 1×2, дуга 140°.

Исходник MA-W09.blend. Новые детали MA-W09-P01/P02/P03 v1.0; фундамент MA-W06-P01 v1.0 и лидар MA-P07 v1.3 повторно использованы без изменений и масштаба. Состав и sockets: assembly.json и composition-plan.md. Превью: Previews/perspective.png, top.png, top-grayscale.png.

Анимация yaw ±70°; elevation и отдача служат демонстрацией авторинга. Физический масштаб BU, LOD, коллайдеры и игровой экспорт не согласованы. GLB не создавался. Игровая интеграция не проверялась.
