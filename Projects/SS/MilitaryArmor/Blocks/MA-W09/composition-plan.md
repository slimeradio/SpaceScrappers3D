# MA-W09 — план состава

Каталог shotgun-turret: 1×2 клетки; одна Barrel Ref shotgun-barrel, 8 ProjectilesPerShot, дуга 140°. Клетки не преобразуются в метры. +Z вверх, -Y вперёд, BU условные. Blender authoring, не игровой контракт.

| Узел | Решение | Совместимость и причина |
|---|---|---|
| Продольный фундамент | Повторно использовать MA-W06-P01 v1.0 | 2.95×6 BU, единичный масштаб, yaw socket Z=1; подходящий 1×2 hardpoint оружейного семейства. Не изменять источник. |
| Широкая низкая люлька | Новая MA-W09-P01 v1.0 | Короткая коробчатая казённая часть с щёками и закрытым приводом; W06-P02 узкая и предназначена длинным рельсам, W05-P02 слишком широкая. |
| Короткий толстый ствол | Новая MA-W09-P02 v1.0 | Один открытый круглый канал, массивная восьмигранная казённая часть, две защищённые направляющие отдачи. W05-P03 веерная щель, W06-P03 длинные рельсы непригодны. |
| Боковой магазин | Новая MA-W09-P03 v1.0 | Один гранёный бочонок поперёк оси; дискретные запирающие сегменты, не набор стволов. Не копировать энергетические кассеты W05/W06. |
| Лидар | Повторно использовать MA-P07 v1.3 | 0.79×0.67 BU, штатный accessory bottom, единичный масштаб, небольшой готовый оптический узел. |

Новые детали отдельно сохранить, проверить manifold/нормали/материалы/вырожденные грани и подготовить perspective/top до assembly. Крепления сопрягаются по логическим полным позам, а не видимому крепежу. Иерархия: Hardpoint → Yaw → Cradle → Elevation → Recoil → Gun; магазин и оптика следуют Yaw. Дуга yaw ±70° по каталогу; elevation и отдача только демонстрация авторинга. Для проверки поз будут отдельные крайние и промежуточные кадры. Отдельно reopen всех деталей и сборки. Общий GLB не создавать.
