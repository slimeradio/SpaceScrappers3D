# MA-E02 — малый тройной двигатель

Каталог thruster-small-3way, 3×2, три сонаправленных источника. Широкая низкая питающая рама с тремя одинаковыми камерами/соплами.

Состав до моделирования: MA-E02-P01 новая трёхканальная рама; MA-E02-P02 новая компактная камера (три экземпляра); MA-E02-P03 явный малый параметрический вариант сопла (три экземпляра), масштабирование большого исходника не используется. Готовый MA-E01-P05 повторно используется как общий компактный сервисный картридж.

Все экземпляры единичного масштаба, +Z вверх, -Y струя, +Y тяга. Название 3way не означает три различных направления. BU условные; игра не меняется. Неподвижная конструкция, постоянного пламени нет.

Финальные файлы: MA-E02.blend, Exports/MA-E02.glb. Состав — assembly.json, проверка — validation.json. Материалы процедурные PBR: Armor/Ceramic/Titanium/Dark и ограниченная бирюзовая эмиссия в горловине/диагностике. Файловых текстур нет. Собственные детали сохранены отдельно; Оба двигателя используют общий компактный картридж MA-E01-P05; прежние исходники не изменены. GLB — для просмотра, без установки в игру.

## Состояния — текущая редакция

Прежние замечания о статике/отсутствии анимаций выше относятся к сохранённой версии до этой правки. Текущий Blender-исходник содержит независимые контролы, управляемые материалы и сохранённые Actions: state-authoring.json. Выбрать объект MA-E02 → Custom Properties; Actions доступны в Action Editor, по умолчанию не назначены. Нагрев/заполнение не сбрасываются отключением. Геометрия неизменённых деталей не пересоздавалась, старые исходники — Versions/StateAnimation-before. Старый validation.json — историческая проверка; новые результаты в state-validation.json. Игровой интеграции и новых GLB нет.
