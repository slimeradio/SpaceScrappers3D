# MA-W07 — пулемётная турель ближней обороны

Компактная одноствольная турель: короткий открытый охлаждающий кожух, асимметричный барабан подачи слева, малый оптический блок справа и трёхлучевая низкая опора.

Три новые отдельные детали MA-W07-P01..P03 v1.0 и сервисный картридж MA-P06 v1.3 без изменений. Редактируемая сборка MA-W07.blend, состав/сокеты/локальные позы — assembly.json, план — composition-plan.md. Отдельные превью деталей находятся в Parts/<ID>/Previews; виды сборки — Previews/perspective.png, top.png, grayscale-top.png.

Каталог: point-defense-turret, 1x1. Сектор поворота 120 градусов; прицеливание и короткая отдача показаны демонстрационной анимацией. BU условные, физический размер не согласован. Метаданные только для авторинга, игровые XML не менялись. GLB не создавался; коллайдеры, LOD, интеграция и игровая проверка не входят в результат.
