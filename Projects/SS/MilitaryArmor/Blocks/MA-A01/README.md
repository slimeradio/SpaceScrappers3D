# MA-A01 — гранёная броня 1x1

Каталог: `armor-1x1`. Одна новая переиспользуемая деталь `MA-A01-P01` v1.0; масштаб экземпляра 1. Ровная несущая кромка высотой 0.16 BU, широкие фаски, срезанные верхние углы и спокойная утопленная панель; стыковочный нижний контур сохранён.

76 треугольников, один меш, два PBR-материала Armor/Ceramic; без файловых текстур, эмиссии и анимации. Логические крепления описаны в part.json.

Источник: `MA-A01.blend`; финальный просмотр: `Exports/MA-A01.glb`. Геометрия источника повторно открыта; GLB импортирован обратно с проверкой числа треугольников, материалов и габаритов. Финальные виды и повторение 4x4 проверяются в TEMP; промежуточных вариантов нет.

BU условны; физический масштаб, коллайдеры и работа в игре не подтверждены.
