# MA-I02 — Грузовой контейнер 2×2

Квадратный цельный грузовой объём с парой крупных загрузочных люков и двумя внешними направляющими. Семейство MA-I01, без аккумуляторных кассет.

5 экземпляров готовых деталей, только 1 новый источник MA-I02-P01; остальные источники повторно используются без изменения и масштаба. Анализ состава composition-plan.md; исходник MA-I02.blend и assembly.json. Проверки validation.json; Previews/top.png, perspective.png, top-grayscale.png.

Визуальная заготовка каталога без игрового XML, вместимость и механика не заданы. BU условные, сетка 2×2 не метры. Статика, процедурные PBR-материалы; без файловых текстур/UV. Контакты опор, уплотнений и обручей конструктивно намеренны. GLB не создавался, игровой интеграции нет.

## Состояния — текущая редакция

Прежние замечания о статике/отсутствии анимаций выше относятся к сохранённой версии до этой правки. Текущий Blender-исходник содержит независимые контролы, управляемые материалы и сохранённые Actions: state-authoring.json. Выбрать объект MA-I02 → Custom Properties; Actions доступны в Action Editor, по умолчанию не назначены. Нагрев/заполнение не сбрасываются отключением. Геометрия неизменённых деталей не пересоздавалась, старые исходники — Versions/StateAnimation-before. Старый validation.json — историческая проверка; новые результаты в state-validation.json. Игровой интеграции и новых GLB нет.
