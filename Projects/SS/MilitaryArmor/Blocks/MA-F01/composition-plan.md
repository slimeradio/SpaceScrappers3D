# MA-F01 — Производственный блок 2×1, переделка v2.0

Направленная технологическая линия: широкий приём слева, круглая защищённая рабочая камера в центре, узкая выдача справа. Поперечный мост на двух опорах, камера остаётся видна сверху. Это художественная интерпретация производства без добавления игровой механики.

Проверка библиотеки и решение ДО моделирования: MA-F01-P01/P02/P03/P04 и общий MA-R01-P05 проверены: два одинаковых прямоугольных люка с поддоном не подходят. Создать MA-F01-R2-P01 направленное основание с приёмом/выдачей, P02 круглая камера, P03 технологический мост. Эти новые детали повторно использовать в MA-F02 без изменения.

Оси +Z вверх, -Y вперёд, правая система. Все экземпляры в единичном масштабе. Новые детали проходят source/evaluated gate и сохраняются отдельно до сборки. Общий восьмигранный картридж не используется. GLB не создавать.
