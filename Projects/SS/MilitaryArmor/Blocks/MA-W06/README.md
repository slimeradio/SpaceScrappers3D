# MA-W06 — Rail sniper

Narrow long split-rail accelerator, four segmented field-coil pairs, aft capacitor keel and precise open muzzle bridge. One central projectile channel.

Editable source: MA-W06.blend. Derived viewer export: Exports/MA-W06.glb. Four new independent source parts MA-W06-P01..P04; MA-P06/MA-P07 1.3 reused at unit scale. Details and attachment plan: composition-plan.md.

Catalog 1x2 grid and 90-degree yaw arc. Elevation/recoil are visual demonstrations. BU physical scale, colliders, LOD and engine integration remain unspecified. Final Blender source and GLB are validated; no game installation performed.
