# MA-W04 / Bastion

Четырёхканальная ракетная установка. Каталог: fleet-rocket-bastion, 3x3 клетки. Широкая ромбическая опора, центральный силовой позвоночник и четыре отдельных клиновидных контейнера в горизонтальной линии. Открытые каналы с утопленными ракетами, короткие броневые направляющие и закрытый привод.

Новые самостоятельные детали: MA-W04-P01…P04 v1.0. Повторно использованы MA-P06/P07 v1.3. Состав и крепления — assembly.json/part.json. Исходник MA-W04.blend; производный экспорт Exports/MA-W04.glb. GLB содержит реальные меши, PBR, иерархию и демонстрационную анимацию.

BU, +Z вверх, -Y вперёд; клетки не метры. Исходники редактируемые, масштаб экземпляров единичный. Игровая интеграция, LOD и коллайдеры не выполнялись. Промежуточные варианты и рендеры не сохранялись.

## Состояния — текущая редакция

Прежние замечания о статике/отсутствии анимаций выше относятся к сохранённой версии до этой правки. Текущий Blender-исходник содержит независимые контролы, управляемые материалы и сохранённые Actions: state-authoring.json. Выбрать объект MA-W04 → Custom Properties; Actions доступны в Action Editor, по умолчанию не назначены. Нагрев/заполнение не сбрасываются отключением. Геометрия неизменённых деталей не пересоздавалась, старые исходники — Versions/StateAnimation-before. Старый validation.json — историческая проверка; новые результаты в state-validation.json. Игровой интеграции и новых GLB нет.
