# MA-I04 — план до моделирования

Каталог cargo-4x4: грузовой контейнер 4×4, visual-only без XML. Вместимость и механизмы не определены. Семейство MA-I01 v2, MA-I02, MA-I03: единый грузовой объём и крупные люки. Две полосы по три люка, цельная широкая крыша, центральный силовой хребет и диагональные боковые контрфорсы.

Повторное использование: MA-I01-R2-P02 v2.0 — 6 готовых люков 2.87×1.29 BU, unit scale; MA-I01-R2-P03 v2.0 — две торцевые направляющие 3.87 BU, unit scale. Материалы и неподвижные sockets совместимы. Корпуса MA-I01-R2-P01 / MA-I02-P01 / MA-I03-P01 не подходят по ширине и схеме посадок: новый MA-I04-P01 7.18×7.08 BU. Новый корпус, не растянутый прежний меш. Грузовые крышки не превращать в отдельные батарейные кассеты. Зазоры люков X=0.49, Y=0.76 BU.

Правая система, +Z вверх, -Y вперёд. BU условные; сетка не метры. Сначала standalone geometry gate, затем сборка экземплярами. Статика; GLB запрещён.
