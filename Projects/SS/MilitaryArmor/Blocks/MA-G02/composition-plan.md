# MA-G02 — план состава

Каталог garage-base: базовый гараж с верфью, 1×1, хранение/выпуск кораблей и Shipyard, Base=true, Capacity4096, Range12. Вместимость не означает число кораблей. BU условные. Статика: новые движения, физический масштаб кораблей и производственные эффекты не вводятся.

| Требование | Кандидат | Решение и причина |
|---|---|---|
| Платформа доступа | MA-G01-P01 v1.0 | Повторно использовать без масштаба: 1.8×1.8 BU, apron/направляющие, совместимые garage.portal/housing sockets. |
| Портал доступа | MA-G01-P02 v1.0 | Повторно использовать без изменений: единый гаражный интерфейс, закрытый доступ -Y. |
| Корпус базы | MA-G01-P03 v1.0 | Создать MA-G02-P01: старый компактный корпус не передаёт усиленную стационарную сервисную структуру. Новый широкий ступенчатый корпус с диагональными боковыми опорами. |
| Верхний узел верфи | Подходящей готовой детали нет | Создать MA-G02-P02: стационарный защищённый сервисный мост с утопленным рабочим полем и двумя силовыми гребнями; без выдуманных подвижных механизмов. |
| Диагностика | MA-R01-P05 v1.0 | Повторно использовать исправленный готовый картридж: совместимый service-cartridge.v1 socket, единичный масштаб. MA-P06 не использовать. |

Материалы выбранного стиля: Armor, Ceramic, Titanium, Steel, Dark и ограниченная Signal. Правые оси +Z вверх, -Y вперёд. Новые детали сначала standalone, материалы, sockets, immediate geometry gate и два preview; только затем сборка и независимое повторное открытие. Сборка содержит пять стабильных экземпляров. GLB не генерировать. Прежние источники не изменять.
