# MA-I01 — Грузовой отсек с верфью 2×1, v2.0

Единый высокий грузовой объём, один крупный загрузочный люк, две направляющие и поперечные силовые рёбра. Прямоугольный цельный силуэт противопоставлен батарейной гребёнке.

Исходник MA-I01.blend, состав assembly.json, предварительный анализ composition-plan.md. 4 экземпляров, 3 новых R2-деталей v2.0; прежние общие источники не изменены. Архив предыдущей версии: ../../Versions/FunctionalIdentity-before/Blocks/MA-I01.

Производные Previews/top.png, perspective.png, top-grayscale.png. Проверки геометрии каждой детали выполнены до сборки. Независимое повторное открытие деталей и сборки, полные позы креплений, версии, материалы и единичные масштабы — validation.json.

Процедурные PBR-материалы, без файловых текстур и зависимости от UV. Статика без выдуманных анимаций. BU условные, сетка 2×1 не метры. Закрытые соединения, уплотнения, защитные кожухи и посадки намеренно касаются/перекрывают сопряжённые компоненты. GLB не создавался, игровая интеграция не выполнялась.
