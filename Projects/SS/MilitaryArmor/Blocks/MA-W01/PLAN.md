# MA-W01 — трёхствольная линкорная артиллерия

Каталог: fleet-artillery-battleship; Turret, сетка 4x4. Три физических снарядных ствола. Размер сетки не определяет метры или габарит меша. BU, +Z вверх, -Y вперёд, единичный масштаб.

План состава до сборки:
- MA-W01-P01: новая широкая ромбовидная монтажная база; MA-P01 имеет неподходящие пропорции для трёх тяжёлых орудий.
- MA-W01-P02: явный новый вариант кольцевого привода, рассчитанный на широкую опору.
- MA-W01-P03: новая стреловидная закрытая бронекапсула с тройным фронтальным проёмом.
- MA-W01-P04: новая поперечная люлька с тремя независимыми направляющими отдачи.
- MA-W01-P05: новый сегментированный снарядный ускоритель; три единичных экземпляра.
- MA-P06 / 1.3: повторно использовать без изменения, сервисная кассета, единичный масштаб.
- MA-P07 / 1.3: повторно использовать без изменения, утопленный лидар, единичный масштаб.

Различимый силуэт: широкая низкая корма, три протяжённых параллельных ствола, диагональные светлые бронеплечи. Бирюзовые элементы только индикаторы ускорителя, привода и оптики. Закрытые механизмы, без танковых решёток/поручней.

Выход: самостоятельные .blend деталей, финальная редактируемая сборка, GLB для просмотрщика. Физический масштаб, коллайдеры, LOD и игровой контракт не определены; установка в игру не выполняется.
