# MA-W02 — турель непрерывного лазера

Одна широкая оптическая апертура с фокусирующими линзами, закрытая поворотная вилка, два радиаторных крыла и вытянутая силовая база. Исходники пяти новых деталей находятся в Parts/MA-W02-P01..05; MA-P06 и MA-P07 версии 1.3 повторно использованы без изменений.

MA-W02.blend — редактируемая сборка; Exports/MA-W02.glb — окончательная модель для просмотрщика с материалами и демонстрационной анимацией. assembly.json хранит состав, иерархию и локальные позы. PLAN.md содержит предварительный план состава.

Style MilitaryArmor 1.3. Exactly one continuous optical emitter; 1x3 catalog grid is not metric mesh size. BU, scale unspecified. Demonstration aiming only; no ballistic recoil. No collider, LOD or game integration.

## Состояния — текущая редакция

Прежние замечания о статике/отсутствии анимаций выше относятся к сохранённой версии до этой правки. Текущий Blender-исходник содержит независимые контролы, управляемые материалы и сохранённые Actions: state-authoring.json. Выбрать объект MA-W02 → Custom Properties; Actions доступны в Action Editor, по умолчанию не назначены. Нагрев/заполнение не сбрасываются отключением. Геометрия неизменённых деталей не пересоздавалась, старые исходники — Versions/StateAnimation-before. Старый validation.json — историческая проверка; новые результаты в state-validation.json. Игровой интеграции и новых GLB нет.
