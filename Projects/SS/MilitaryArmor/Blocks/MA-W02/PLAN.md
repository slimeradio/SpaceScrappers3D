# MA-W02 — турель непрерывного лазера

Каталог: continuous-laser-turret; Turret, сетка 1x3. Ровно один continuous-emitter. Размер сетки не определяет метры или габарит меша. BU, +Z вверх, -Y вперёд, единичный масштаб.

План состава до сборки:
- MA-W02-P01: новая узкая вытянутая силовая база; геометрия MA-P01 слишком широка.
- MA-W02-P02: новая низкая азимутная опора с U-образной вилкой, поддерживающая оптику.
- MA-W02-P03: новый компактный многогранный корпус оптической системы.
- MA-W02-P04: новый короткий широкий оптический излучатель с концентрическими линзами и ирисом; один экземпляр.
- MA-W02-P05: новый боковой многослойный радиатор, два единичных экземпляра.
- MA-P06 / 1.3: повторно использовать без изменения, сервисная кассета, единичный масштаб.
- MA-P07 / 1.3: повторно использовать без изменения, утопленный лидар, единичный масштаб.

Различимый силуэт: вытянутая база, короткая широкая оптическая апертура между охлаждающими крыльями, закрытая поворотная вилка. Никаких баллистических стволов и снарядной отдачи. Бирюзовая оптическая поверхность, сдержанные диагностические щели.

Выход: самостоятельные .blend деталей, финальная редактируемая сборка, GLB для просмотрщика. Физический масштаб, коллайдеры, LOD и игровой контракт не определены; установка в игру не выполняется.
