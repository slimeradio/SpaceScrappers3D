# Все текущие блоки MilitaryArmor

AllBlocks.blend — одна редактируемая Blender-сцена со всеми 58 текущими сборками из MilitaryArmor/Blocks/. Другие стили и архивные варианты в сцену не включены; реактор соответствует возвращённой пользователем исходной версии, аукцион — текущей версии 3.0.

Блоки расположены по сетке 8×8 с широкими свободными промежутками. Масштаб экземпляров единичный, исходные пропорции сохранены. У каждой модели отдельная коллекция с её ID и родительский объект Exhibit.<ID>. Подписи содержат ID и название из общего каталога SS; шрифт упакован в сцену. Представительские камеры/свет/подписи/пол выделены в отдельную коллекцию Presentation. Студийный пол исходной тестовой турели исключён, экземпляры её коллекций раскрыты в редактируемые объекты внутри сцены.

Камеры Camera.Overview и Camera.Perspective дают виды сверху и в объёме. Предпросмотры — Previews/overview.png и Previews/perspective.png. Все модели находятся в одной сцене MilitaryArmor.AllBlocks; коллекции можно независимо скрывать, изолировать и редактировать. Перемещение всего блока выполняется через его Exhibit.<ID>.

Сцена содержит собственные копии объектов и материалов. Редактирование этой сцены не перезаписывает исходные модели. Сборки и детали не пересоздаются: используются сохранённые Blender-источники. Исходные координаты и единицы — условные BU, без утверждения физического масштаба в метрах.

scene.json содержит список блоков, исходные пути/хеши, габариты и размещение. validation.json — повторное открытие сохранённой сцены, полнота текущего набора, отсутствие перекрытия габаритов соседних блоков, материалы и сохранность источников. Глубокая геометрическая проверка неизменённых исходных деталей не повторялась.

Создание: Blender --background --factory-startup --python Tools/build_all_blocks_scene.py (из корня стиля нужен абсолютный путь к скрипту или путь относительно рабочего каталога). Режимы после --: --verify проверяет сохранённую сцену; --render-only обновляет только её предпросмотры. Эти режимы не меняют источники блоков. GLB не создаётся.
