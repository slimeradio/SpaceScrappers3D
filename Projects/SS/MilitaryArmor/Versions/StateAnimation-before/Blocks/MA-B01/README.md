# MA-B01 — Батарея 4×4, v2.0

Гребенчатый силуэт: семь узких энергомодулей, открытые промежутки и два силовых распределителя. Общего поддона, крупных крышек и сервисного картриджа нет.

Исходник MA-B01.blend, состав assembly.json, предварительный анализ composition-plan.md. 10 экземпляров, 3 новых R2-деталей v2.0; прежние общие источники не изменены. Архив предыдущей версии: ../../Versions/FunctionalIdentity-before/Blocks/MA-B01.

Производные Previews/top.png, perspective.png, top-grayscale.png. Проверки геометрии каждой детали выполнены до сборки. Независимое повторное открытие деталей и сборки, полные позы креплений, версии, материалы и единичные масштабы — validation.json.

Процедурные PBR-материалы, без файловых текстур и зависимости от UV. Статика без выдуманных анимаций. BU условные, сетка 4×4 не метры. Закрытые соединения, уплотнения, защитные кожухи и посадки намеренно касаются/перекрывают сопряжённые компоненты. GLB не создавался, игровая интеграция не выполнялась.
