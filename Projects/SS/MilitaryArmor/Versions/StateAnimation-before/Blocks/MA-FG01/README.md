# MA-FG01 — Машинное отделение 3×3, v2.0

Асимметричный технологический силуэт: высокий продольный барабан слева, поперечный коллектор сзади и две малые насосные головы справа, защищённые магистрали между ними. Нет сетки одинаковых крышек.

Исходник MA-FG01.blend, состав assembly.json, предварительный анализ composition-plan.md. 5 экземпляров, 4 новых R2-деталей v2.0; прежние общие источники не изменены. Архив предыдущей версии: ../../Versions/FunctionalIdentity-before/Blocks/MA-FG01.

Производные Previews/top.png, perspective.png, top-grayscale.png. Проверки геометрии каждой детали выполнены до сборки. Независимое повторное открытие деталей и сборки, полные позы креплений, версии, материалы и единичные масштабы — validation.json.

Процедурные PBR-материалы, без файловых текстур и зависимости от UV. Статика без выдуманных анимаций. BU условные, сетка 3×3 не метры. Закрытые соединения, уплотнения, защитные кожухи и посадки намеренно касаются/перекрывают сопряжённые компоненты. GLB не создавался, игровая интеграция не выполнялась.
