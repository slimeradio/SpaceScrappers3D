# MA-D03 — Механический бур 3×5

Три зубчатые конические головки, центральная вынесена вперёд. Длинная открытая силовая рама с тремя распределительными кожухами, диагоналями и кормовым мостом. Три готовых редуктора и три готовых инструмента не растянуты.

Каталог rotary-drill-3x5, визуальная заготовка без игрового XML. Условные BU, +Z вверх, -Y направление инструмента. Новая MA-D03-P01 v1.0; MA-D01-P02 и MA-D01-P03 v1.0 использованы по три раза без изменений. Семь стабильных экземпляров с единичным масштабом. Полные позы совместимых креплений. Статика без анимаций. Процедурные материалы без файловых текстур/UV; штатные небольшие индексы приводов светятся.

Исходник MA-D03.blend; Previews/top.png, perspective.png, top-grayscale.png. Новая деталь проверена до сборки. Независимый verifier повторно открывает источники и сборку, проверяет валы/муфты и оси инструмента. Нет GLB, игровых параметров, LOD, коллайдеров или установки в игру.
