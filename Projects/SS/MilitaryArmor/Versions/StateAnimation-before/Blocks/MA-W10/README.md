# MA-W10 — малая импульсная лазерная турель

Открытый оптический стенд с разнесёнными керамическими направляющими, короткая фокусирующая апертура, задний резонатор и одна боковая импульсная кассета. Одна линза и один импульсный луч по каталогу, сетка 1×3.

Новые детали MA-W10-P01/P02 и вариант кассеты MA-W10-P03; база MA-W02-P01, линза MA-W02-P04 и сервис MA-P06 повторно использованы без изменения и масштаба. Исходник MA-W10.blend; состав/sockets/позы assembly.json, план composition-plan.md. Превью perspective.png, top.png, top-grayscale.png в Previews.

Полный оборот360° за4секунды (90°/с), демонстрационное склонение без отдачи. BU условные, коллайдеры и LOD не заданы. Только авторинг, игровой запуск не проверялся; GLB не создавался.
