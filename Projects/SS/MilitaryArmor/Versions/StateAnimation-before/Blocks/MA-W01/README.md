# MA-W01 — линкорная артиллерия

Три отдельных сегментированных снарядных ускорителя, закрытая люлька и стреловидная многогранная бронекапсула. Исходники пяти новых деталей находятся в Parts/MA-W01-P01..05; MA-P06 и MA-P07 версии 1.3 повторно использованы без изменений.

MA-W01.blend — редактируемая сборка; Exports/MA-W01.glb — окончательная модель для просмотрщика с материалами и демонстрационной анимацией. assembly.json хранит состав, иерархию и локальные позы. PLAN.md содержит предварительный план состава.

Style MilitaryArmor 1.3. Three physical projectile channels; 4x4 catalog grid is not metric mesh size. BU, scale unspecified. Demonstration aiming/recoil only. No collider, LOD or game integration.
