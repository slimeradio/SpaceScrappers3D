# MA-SP01 — функциональная переделка 2.0

Солнечная панель: единое тонкое поле пассивных фотоэлементов, скошенные торцы, тонкая кромка и две поперечные опоры под полем. Сплошной спокойный силуэт противопоставлен открытой гребёнке радиатора. Без эмиссии и раскладных механизмов. Визуальная заготовка без игрового XML, мощность не задавалась.

Редактируемый MA-SP01.blend. Все детали — отдельные неизменяемые источники Parts/*-R2-P*/ v2.0; состав, версии, полные позы и совместимость logical sockets: assembly.json / part.json. Старые детали сохранены. Сетка каталога [1, 2]; BU условны, +Z вверх, -Y вперёд, правая система. Масштабы экземпляров единичные. Статичная конструкция, анимаций нет.

Процедурные PBR без файловых текстур и UV-зависимости. Геометрия каждого источника проверена ДО сборки. validation.json — независимое повторное открытие источников и сборки, source/evaluated geometry, версии, ссылки, полные позы и совместимость sockets. Виды Previews/top.png, perspective.png; top-grayscale.png — нейтральный clay override, исходные материалы не изменены.

Прилегание вложенных оболочек, тонких облицовок и опор намеренное. Полые пространства между секциями открыты. Исторический блок сохранён в Versions/FunctionalIdentity-before/Blocks/MA-SP01; старые Parts сохранены по исходным путям. Новые GLB не создавались. Игровая интеграция, коллайдеры и LOD не выполнялись.
