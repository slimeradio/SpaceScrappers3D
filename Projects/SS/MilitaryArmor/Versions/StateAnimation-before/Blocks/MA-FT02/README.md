# MA-FT02 — Бак топлива 2×2

Две раздельные продольные ёмкости с обручами на поперечных опорах. Открытые промежутки и видимые торцы сосудов различают бак и цельный контейнер.

7 экземпляров готовых деталей, только 1 новый источник MA-FT02-P01; остальные источники повторно используются без изменения и масштаба. Анализ состава composition-plan.md; исходник MA-FT02.blend и assembly.json. Проверки validation.json; Previews/top.png, perspective.png, top-grayscale.png.

Визуальная заготовка каталога без игрового XML, вместимость и механика не заданы. BU условные, сетка 2×2 не метры. Статика, процедурные PBR-материалы; без файловых текстур/UV. Контакты опор, уплотнений и обручей конструктивно намеренны. GLB не создавался, игровой интеграции нет.
