# MA-D02 — Механический бур 2×3

Два отдельных конических шнека со сменными зубьями, два закрытых редуктора, широкая силовая траверса и наружные опорные полозья. Общий облик семейства MA-D01 сохранён; широкая двухвальная компоновка не получена растяжением одиночного бура.

Каталог: rotary-drill-2x3. Визуальная заготовка без игрового XML; производительность и физический масштаб не заданы. +Z вверх, -Y направление инструмента; BU условные. Исходник: MA-D02.blend. Новая деталь MA-D02-P01; MA-D01-P02 и MA-D01-P03 версии 1.0 повторно использованы по два раза без изменения. Пять экземпляров, единичный масштаб, полные локальные позы креплений. Статика без анимаций, искр и лучей. Процедурные материалы Blender; нет файловых текстур или UV. Эмиссия — небольшие штатные диагностические индексы приводов.

Предпросмотры: Previews/top.png, perspective.png, top-grayscale.png. Проверки исходников выполнены до сборки, независимая проверка повторно открывает все .blend. GLB не генерировался. Игровой экспорт, коллайдеры и LOD не входят в текущий авторинг.
