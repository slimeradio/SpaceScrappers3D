# MA-F02 — Производственный блок базы 2×1, v2.0

Базовая версия производственного семейства: общие с MA-F01 приём, круглая камера, выдача и мост; собственный ступенчатый сервисный узел сзади. Семейное сходство производства сохранено намеренно. Подбор деталей до моделирования: composition-plan.md. Редактируемый исходник MA-F02.blend; состав и точные версии в assembly.json.

Детали: MA-F01-R2-P01 v2.0, MA-F01-R2-P02 v2.0, MA-F01-R2-P03 v2.0, MA-F02-R2-P01 v2.0. Каждая новая деталь прошла геометрический gate ДО сборки, сохранены самостоятельные top/perspective.

Сборка: Previews/top.png, perspective.png и top-grayscale.png (временный единый серый материал только при рендере, материалы исходника сохранены). validation.json создаёт независимая повторная проверка исходников и сборки. Все экземпляры единичного масштаба; полные позы и семантическая совместимость sockets проверены.

Версия до переделки: ../../Versions/FunctionalIdentity-before/Blocks/MA-F02/. Старые детали не изменены. Статика, без анимаций, файловых текстур и UV-зависимости; процедурные PBR-материалы. BU условные, не метры. GLB не создавались. Игровая интеграция, коллайдеры и LOD не выполнялись. Контакты опор, оболочек и защищённых подключений намеренны.
