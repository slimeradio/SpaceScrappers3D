# MA-D01 — Механический бур 1×3

Каталог: rotary-drill-1x3, визуальная заготовка без игрового XML. Назначение выражено открытой несущей рамой, защищённым редуктором и широким коническим режущим шнеком с тремя винтовыми гребнями и сменными зубьями. Нет лазерного канала или пушечного среза.

Исходник: MA-D01.blend. Три отдельные редактируемые детали MA-D01-P01, P02, P03 версии 1.0; экземпляры с единичным масштабом, логические крепления полностью совмещены по позиции и ориентации. +Z вверх, -Y рабочее направление, BU условные. Статическая исходная поза, анимаций нет. Ось инструмента — ориентир авторинга, не игровой контракт.

Предпросмотры: Previews/top.png, perspective.png, top-grayscale.png. Процедурные материалы Blender; файловых текстур и UV нет; эмиссия только небольшого индикатора привода. В каждом part.json перечислены поверхности, материалы и крепления. Проверки геометрии выполнены до сборки. Производительность добычи, коллайдеры, LOD и игровой экспорт не заданы. GLB не создавался.
