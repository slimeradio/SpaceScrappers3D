# MA-I05 — грузовой контейнер 5×5

Цельный широкий контейнер: две полосы по четыре крупных загрузочных люка, приподнятый силовой хребет, торцевые усиления и диагональные контрфорсы. Компоновка сохраняет грузовое семейство и отличается от открытой гребёнки батареи.

13 экземпляров, 3 источника: новый MA-I05-P01 v1.0; 8 люков MA-I01-R2-P02 v2.0 и 4 направляющие MA-I01-R2-P03 v2.0 повторно использованы без изменений и масштаба.

Редактируемый MA-I05.blend; assembly.json, composition-plan.md, validation.json. Previews/top.png, perspective.png, top-grayscale.png. Процедурные PBR без файловых текстур/UV; эмиссия только в индексах готовых люков. Статическая visual-only модель без XML, вместимости, анимаций и игрового экспорта. GLB не создавался; BU не метры.
