# MA-FT04 — бак топлива 4×4

Восемь продольных ёмкостей с суженными торцами: четыре дорожки по две секции. Светлые силовые обручи, открытые боковины и видимые торцы сохраняют топливное семейство MA-FT01/MA-FT02. Между рядами — низкий защищённый распределитель; опоры раздельные, без поддона и крупной сервисной крышки. От теплоаккумулятора отличается продольными сосудами с тонкими обручами, от контейнера — открытыми промежутками и отсутствием грузовых люков.

Редактируемый MA-FT04.blend; состав assembly.json; план повторного использования composition-plan.md. 25 экземпляров: одна новая MA-FT04-P01 v1.0, восемь готовых MA-FT01-P02 v1.0 и шестнадцать готовых MA-FT01-P03 v1.0. Исходники готовых деталей не изменены; единичный масштаб. Геометрия новой детали проверена немедленно до сборки. Независимое открытие исходников/сборки и полные позы креплений — validation.json.

Previews/top.png, perspective.png, top-grayscale.png. Статический концепт, процедурный PBR, без эмиссии, UV-зависимости и файловых текстур. Условные BU, сетка 4×4 не метры. Каталог visual-only без игрового XML; вместимость, давление и игровые свойства не задавались. Посадки сосудов, обручей и присоединений имеют намеренное заглубление; коллайдеры и LOD не создавались. GLB и игровая интеграция не выполнялись.
