# MA-S01 — аукцион базы, v3.0

Низкий трёхлучевой коммуникационный узел торговой инфраструктуры. Три защищённых интерфейсных гнезда направлены к узкой центральной камере; асимметричная сервисная спина и утопленные малые индексы. Большой экран исключён. Назначение и ограничения: auction-base, 1×1; модель не меняет игровые условия рынка.

Редактируемый исходник MA-S01.blend, состав assembly.json, выбор деталей composition-plan.md. Четыре новые самостоятельные детали MA-S01-R3-P01…P04 v3.0, шесть экземпляров. Геометрические gates до сборки; независимая повторная проверка в validation.json. Top/perspective/top-grayscale в Previews. Все sockets совмещены по позиции и ориентации, unit scale. Материалы процедурные PBR, без файловых текстур, анимаций и UV-зависимости. BU условные. GLB не создавались.

Отвергнутая v2 сохранена в ../../Versions/Auction-v2-rejected/Blocks/MA-S01/; v1 в ../../Versions/FunctionalIdentity-before/Blocks/MA-S01/. Старые Parts не изменены. Игровая интеграция/LOD/коллайдеры не выполнялись.
