# MA-R01 — реактор

Каталог reactor-4x4-aaaa, сетка 4×4. Герметичный центральный корпус, четыре стреловидных экрана, четыре закрытые термокассеты на диагональном основании. Бирюзовая эмиссия только в диагностике.

Исходник: MA-R01.blend. Предпросмотры: Previews/MA-R01-perspective.png и Previews/MA-R01-top.png. Состав и логические соединения — assembly.json; независимая проверка — validation.json.

Пять новых самостоятельных деталей MA-R01-P01…P05, включая явный вариант MA-P06 v1.3: тот же картридж с исправленными радиусами фасок. Прежняя деталь не изменялась. Всего 11 экземпляров. У каждой новой детали исходник, метаданные, предпросмотр и геометрическая проверка до включения в сборку.

Процедурные PBR Blender, файловых текстур/UV нет. Статичная конструкция без анимаций. Все экземпляры единичного масштаба; BU условные, +Z вверх, -Y вперёд. GLB не создавался. Исходник не устанавливался и не проверялся в игре, игровой контракт, LOD, коллайдеры и физический масштаб не задаются этой моделью.
