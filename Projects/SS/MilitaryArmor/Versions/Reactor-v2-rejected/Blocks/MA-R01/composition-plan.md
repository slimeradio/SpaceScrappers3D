# MA-R01 — план функциональной переделки 2.0

Реактор 4×4: центральная цельная камера, концентрическое экранирование и радиальные силовые связи. Оси +Z вверх, -Y вперёд; unit scale; BU условные. Каталожная сетка не равна метрам. Никаких новых игровых механизмов или анимаций.

| Узел | Проверенный существующий кандидат | Решение и причина |
|---|---|---|
| Основание | MA-R01-P01 v1.0: квадратное шасси | Новая MA-R01-R2-P01: кольцевой низкий экран с восемью радиальными опорами, круговой силуэт |
| Камера | MA-R01-P02 v1.0 / MA-R01-P05: прежний корпус с главной восьмигранной крышкой | Новая MA-R01-R2-P02: высокая закрытая ступенчатая камера, кольца и радиальные рёбра. Общий картридж не используется |

Сначала самостоятельные детали R2 v2.0: исходник, материалы, полные sockets, проверка source/evaluated mesh и два превью. Затем экземпляры в сборке. Старые Parts не изменяются. Архив исходного блока: ../../Versions/FunctionalIdentity-before/Blocks/MA-R01/; архивные ссылки source явно перенаправлены на ../../../../Parts, неизменённые старые Parts сохранены по прежним путям. Источники Blender содержат встроенную геометрию и материалы. GLB не создаётся.
