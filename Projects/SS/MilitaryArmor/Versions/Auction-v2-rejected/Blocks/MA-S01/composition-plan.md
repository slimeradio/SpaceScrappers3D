# MA-S01 — план функциональной переделки 2.0

Аукцион 1×1: направленный консольный терминал, широкий наклонный интерфейс как главный объём. Оси +Z вверх, -Y вперёд; unit scale; BU условные. Каталожная сетка не равна метрам. Никаких новых игровых механизмов или анимаций.

| Узел | Проверенный существующий кандидат | Решение и причина |
|---|---|---|
| Опора | MA-N01-P01 / MA-S01-P02: квадратное шасси и бронеплечи | Новая MA-S01-R2-P01: узкая задняя стойка и расходящиеся передние опоры; форма терминала вместо ящика |
| Интерфейс | MA-S01-P01: низкий сервисный интерфейс | Новая MA-S01-R2-P02: большой наклонный защищённый дисплей с нижней панелью; общий картридж MA-R01-P05 не используется |

Сначала самостоятельные детали R2 v2.0: исходник, материалы, полные sockets, проверка source/evaluated mesh и два превью. Затем экземпляры в сборке. Старые Parts не изменяются. Архив исходного блока: ../../Versions/FunctionalIdentity-before/Blocks/MA-S01/; архивные ссылки source явно перенаправлены на ../../../../Parts, неизменённые старые Parts сохранены по прежним путям. Источники Blender содержат встроенную геометрию и материалы. GLB не создаётся.
