# MA-HS01 — план состава до геометрии

Каталог: heat-store-1x1, визуальная заготовка 1×1 без игрового XML. Единицы BU условные, правая система +Z вверх, -Y вперёд. Стиль MilitaryArmor 1.3: закрытый компактный броневой термоаккумулятор, три защищённые кассеты, торцевые коллекторы. Без эмиссии, открытого ядра, выдуманных температур и ёмкости.

| Требуется | Проверенная библиотека | Решение |
|---|---|---|
| Основание и коллекторы 1×1 | MA-H01-P01 имеет поле 1×2, MA-N01-P01 является закрытым антенным корпусом с иной компоновкой и sockets | Новая MA-HS01-P01; не масштабировать специализированные корпуса |
| Закрытая термокассета | MA-H01-P02 — плоская радиационная плитка, аккумуляторные ячейки MA-B01-P02 другого назначения | Новая MA-HS01-P02; три единичных экземпляра, без анимаций |
| Защитные термопанели | MA-E01-P04 v1.0: 0.104×1.11×0.46 BU, Ceramic/Titanium, без эмиссии, root совместим с MilitaryArmor.engine.thermal | Повторно использовать два экземпляра при единичном масштабе, новые посадочные места совместимы |

Kits в стиле отсутствует. Геометрия каждой новой детали проверяется отдельно до сборки. Все существующие исходники остаются неизменны. GLB не создавать. Взаимное заглубление крышек в корпус кассеты и опор в основание — намеренные конструктивные контакты.
