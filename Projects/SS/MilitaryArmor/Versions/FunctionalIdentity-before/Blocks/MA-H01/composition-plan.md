# MA-H01 — план состава

Каталог radiator-1x2, 1×2, визуальная заготовка без игрового XML. Статика, без выдуманных тепловых параметров.

| Деталь | Решение |
| --- | --- |
| MA-M02-P04 v1.0 .35×3.8×.517 BU | Не подходит: закрытый промышленный узел длиннее рамы; масштабирование запрещено. |
| MA-E01-P04 v1.0 .104×1.11×.460 BU | Повторно использовать четыре раза как защищённые боковые термопанели, единичный масштаб, без эмиссии. Рама предоставляет совместимые engine.thermal sockets. |
| Силовая рама с коллектором | Создать MA-H01-P01: готовой рамы для радиационного поля нет. |
| Широкие радиационные поверхности | Создать повторяемую MA-H01-P02, восемь экземпляров. E01-P04 слишком узкая. |
| Сервисный картридж | Не нужен, лишняя диагностика не добавляется. |

Сначала standalone детали, материалы, полные sockets, top/perspective и geometry gate; затем сборка. Старые исходники не меняются, GLB не генерируется.
