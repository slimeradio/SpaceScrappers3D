# MA-T01 — тестовая двухствольная бронетурель

Визуальный прототип для `fleet-artillery-corvette`: каталог задаёт сетку 2×3, два ствола и круговое наведение. Сетка не задаёт метрические размеры этой модели. Игровые координаты выстрела требуют отдельного согласования масштаба при интеграции.

План состава (библиотека нового стиля пуста; все детали создаются впервые, версия 1.0):

| ID детали | Назначение | Решение и причина |
|---|---|---|
| MA-P01 | Бронированное основание | Новая: неподвижный силовой корпус |
| MA-P02 | Поворотный погон | Новая: интерфейс основания и башни |
| MA-P03 | Бронекорпус башни | Новая: наклонные щёки и кормовой противовес |
| MA-P04 | Маска парных орудий | Новая: единый узел возвышения |
| MA-P05 | Орудийный ствол | Новая: два экземпляра одной готовой детали |
| MA-P06 | Сервисный люк | Новая: повторяемая накладная панель |
| MA-P07 | Оптический модуль | Новая: прицел и сигнальные огни |
| MA-P08 | Поручень | Новая: повторяемое палубное крепление |

Все экземпляры используют единичный масштаб. Исходник сборки: `MA-T01.blend`; состав, родительские узлы и локальные преобразования: `assembly.json`. Погон и башня вращаются вокруг Z; маска и стволы поднимаются вокруг X. Отдача двух стволов — локальное движение назад по +Y. Демонстрационные клипы не определяют игровой темп стрельбы. Проверочные позы включают -8°, 0°, +25° возвышения и поворот на 180°.

Материалы процедурные: графитовая броня, сталь, тёмный механизм, маркировка, оптика и тёплая эмиссия (Blender strength 3). Текстовые обозначения — редактируемые кривые Blender. Исходники не требуют внешних шрифтов и файловых карт. Превью деталей и сборки лежат в `Previews/`; проверка и измерения — в `validation.json`.

Это тест художественного направления. Игровой экспорт, LOD, коллайдеры и проверка в игре не выполнялись.
