# MilitaryArmor — просмотр Blender и состояний

Просмотрщик доступен через serve.ps1 и viewer.html. Он автоматически находит все 64 текущие сборки Blocks/ по их Blender-исходникам; старые GLB не используются для этого стиля.

В блоке «Состояния блока» показаны только подключённые к видимому движению/материалам параметры, а также независимое питание. У радиатора доступны открытая/закрытая поза, плавное раскрытие, нагрев и горячее состояние без питания. У производства — запуск, рабочий цикл и остановка. Ручная смена параметра останавливает только конфликтующее движение и сохраняет остальные значения. Изменение нагрева не прерывает раскрытие. Состояние «Работает» автоматически запускает рабочий цикл, если он есть. Рабочая фаза сохраняется при переходе между клипами; полные обороты повторяются визуально непрерывно. Панель «Анимации» содержит воспроизведение, паузу, остановку, позицию и скорость.

Кнопка «Открыть GLB / blend…» и перетаскивание принимают .blend. При открытии файла блока MilitaryArmor считываются его сохранённые контролы и Actions; для обычного .blend поддерживаются объектные анимации текущей сцены. Список деталей, выбор экземпляра, изоляция, камера и оформление сохранены. Экспорт модели из браузера фиксирует текущую позу; управляемый исходник остаётся в Blender.

## Хранение и обновление

- /api/catalog — общие записи каталога плюс текущие Blender-сборки MilitaryArmor.
- /api/blend/<ID> — геометрия, иерархия, PBR-материалы, безопасное дерево математических выражений драйверов и ключи управляющих Actions.
- Exports/ViewerStates/<ID>/scene.json — производный кэш. Хеш учитывает исходный .blend, assembly.json, state-authoring.json и преобразователь; новый исходник автоматически заменяет кэш.
- Исходники .blend не перезаписываются. GLB не создаются. Подготовка выполняется с отключённым автоматическим исполнением встроенных скриптов файла.

Веб-представление сохраняет вычисленную геометрию и базовые PBR-параметры. Процедурные графы шейдеров Blender не исполняются в браузере. Это просмотр ассета, а не интеграция состояний в игру.

## Проверки

Exports/ViewerStates/prepared.json подтверждает подготовку всех 64 текущих моделей. browser-acceptance.json содержит результат проверки в реальном браузере: открытие .blend через файловый ввод, раскрытие/нагрев радиатора, сохранение жара без питания, рабочий цикл и ручная остановка переработчика, статичная броня, крупный радиатор, оружие, тройной двигатель и накопитель тепла. Отдельный простой файл проверяет сохранение обычной объектной анимации при импорте. Снимки radiator-warm.png, radiator-closed-hot.png и refinery.png показывают результат.

Повторение локальной приёмки: подготовить тестовый файл скриптом Viewer/test_blend_fixture.py через Blender, затем запустить Viewer/test_states.cjs доступным Node.js с установленным Playwright и Edge. Тестовые и производные файлы находятся в Exports/ViewerStates/, вне исходников Parts/ и Blocks/.
